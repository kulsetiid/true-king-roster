使用前准备

准备已有的 SillyTavern、酒馆助手、MVU、EjsTemplate 及兼容角色卡。模型连接由您自己配置。同一酒馆只启用一份真王核心。

网络版安装

  1. 下载 JSON，在酒馆助手脚本管理中导入并启用。
  2. 刷新酒馆，打开目标角色卡。
  3. 在安装面板点击“安装到当前角色卡”，等世界书和美化显示完成。
  4. 点击小帮手打开菜单。手机请横屏，无需启动 Windows 包。

本地版安装

  1. 下载 ZIP，完整解压到独立文件夹。
  2. 双击“真王核心.exe”，选择已有酒馆文件夹和账号。
  3. 等待当前正文生成结束，点击“安装 / 更新完整组件”；由其他入口启动的酒馆先正常退出。
  4. 酒馆启动后打开目标角色卡，点击“安装到当前角色卡”，确认完成。
  5. 以后从同一个 EXE“连接并启动”。保留整个解压文件夹。
