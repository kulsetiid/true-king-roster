- 小帮手八项快捷入口：孤儿院、花名册、姬月的愿望、天使邮路、储藏室、虚空武装、秘密补给、塔罗占卜。

- 导购购买凭证，兑换时交由正文主模型按当前角色卡规则生成；保留原价格与冠冕之灵身份对应。
- 快捷菜单打开功能后直接返回酒馆；从孤儿院进入仍返回孤儿院，内部详情和设置保持自己的返回层级。
- 配套世界书固定入口及八组角色美化安装；原聊天、FP、背包和房间布置沿用。

## 先准备

已有的 SillyTavern 酒馆、酒馆助手、MVU 和提示词模板插件（EjsTemplate），以及兼容角色卡和模型连接。本包不是酒馆本体，也不包含模型服务或 API 密钥。

同一酒馆只启用一份真王核心。本地版与网络版二选一；旧版使用相同核心编号，若助手保留了副本，请停用旧副本后刷新。

## 网络版：电脑、手机或远程酒馆

1. 下载上面的“网络版导入文件”，在酒馆助手的脚本管理中导入并启用。
2. 刷新酒馆，打开要使用的角色卡。
3. 在“真王核心 · 完整组件安装”面板点击“安装到当前角色卡”，待世界书及美化显示安装完成。
4. 点击酒馆里的小帮手展开快捷菜单。首次下载需要联网；额外功能的模型连接可在花名册 API 页设置。

手机请横屏使用。手机和远程端无需运行 Windows 一键包，资源通过 HTTPS 直接加载。

纸卡与音乐沿用独立素材发布方式：以内容哈希命名、固定版本地址读取、按需加载并复用浏览器缓存。代码与素材分开下载；图片保留原尺寸与透明通道，缓存被清除后会重新下载。

旧的一行加载地址继续有效，刷新获取 V3：

```js
import 'https://kulsetiid.github.io/true-king-roster/index.js';
```

下载的 RC16 导入文件使用固定版本地址；以后升级可重新导入新版。

## 本地一键包：Windows 10/11 x64

1. 从 [GitHub Release 下载完整 ZIP](https://github.com/kulsetiid/true-king-roster/releases/download/v3-rc16-scalefix-20261118/TrueKing-V3-RC16-ScaleFix-Windows-x64.zip)，**先完整解压**到一个独立文件夹。
2. 双击 `真王核心.exe`，选择已有的 SillyTavern 文件夹（其中应有 `server.js`）。
3. 选择自己的账号，点击“安装 / 更新完整组件”。更新前先等正文生成结束；由其他入口启动的酒馆请先正常退出。
4. 酒馆启动后，进入目标角色卡，点击“安装到当前角色卡”。等世界书、美化逐项显示成功，再点“完成”。
5. 日常使用双击同一个 `真王核心.exe`，点击“连接并启动”，然后点击酒馆页面的小帮手。

本包自带运行环境，无需另外安装 Node.js。纸剧场图片、音乐与人物文本从包内“本地内容”读取，利维娅对白的表情图片通过 ImgBB 联网加载；核心的本机读取服务使用 4196 端口。本地资源可离线读取，模型生成功能仍需自己的模型连接。

请保留整个解压文件夹，不要单独移动 EXE。升级时解压到新文件夹，再执行安装更新。首次安装后也可在安装器打开素材预览。

## 更新、回退与常见情况

- 更新前会备份核心；启动器“回退核心”恢复入口。酒馆内“撤回上次组件安装”恢复该次世界书与美化安装。
- 没有小帮手：确认脚本和助手总开关已启用，并刷新酒馆；检查是否同时启用了旧版。
- 没出现安装目标：先打开角色卡，再点安装；不要停留在酒馆首页。
- 本地资源无法读取：启动解压目录中的 EXE，确认本包服务运行；若旧包占用 4196，先在旧包停止其服务，再启动新包。
- 手机竖屏会提示旋转；远程酒馆请选择网络版，Windows 本地包的 127.0.0.1 地址不供其他设备访问。
- 安装包的 SHA-256 校验文件随 Release 提供。
