# 真王核心-纸剧场

当前版本：**V0.3.22**。用于SillyTavern酒馆助手与MVU。

## 本次更新

- 克里斯蒂娜正式加入纸剧场，包含抱书、读书、绘画、旋舞及点击回应。
- 接入定稿人物档案、四项权柄、双向关系及纸卡技能图标。
- 人物选单与书桌牌盒进入塔罗占卜；占卜桌上的牌盒打开牌册，书籍打开手记。
- 花名册统一API设置支持获取模型、上下文预算与解锁上下文长度，默认在当前浏览器记住密钥并支持清除。
- 调整塔罗占卜与秘密补给的入口纸签位置。
- 新增克里斯蒂娜对白正则：16种已定稿mood、奶白纸卡、拉丁文署名、85%不透明度灰底。

## 安装与更新

已有网络加载版的用户刷新酒馆即可获取主脚本更新；克里斯蒂娜对白正则需单独导入。新版脚本名称为“真王核心-纸剧场”，脚本ID沿用原“真王核心-花名册”，升级时替换原脚本，只保留一个版本启用。

新用户先安装酒馆助手、MVU及配套角色卡，再导入网络加载JSON、固定世界书和需要的对白正则。

## 一行网络加载

```js
import 'https://kulsetiid.github.io/true-king-roster/index.js';
```

网络加载版跟随同一地址更新；轻量联网版固定使用下载时的脚本。二者均按需加载图片。当前脚本约4.31MB，167张运行素材合计约116.11MB。图片主源为GitHub Pages，失败时使用固定素材标签assets-v0.3.22的jsDelivr地址。

密钥按设置仅保存在用户当前浏览器，发布包不包含本地密钥、聊天存档或开发配置。

本次使用已完成的V0.3.22克里斯蒂娜整合包生成联网成品；未新增运行本地测试或实际酒馆导入。
