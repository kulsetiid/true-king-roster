# 真王核心 · 轻量联网版

版本：V0.3.12。

```js
import 'https://kulsetiid.github.io/true-king-roster/index.js';
```

仍使用原来的一行导入地址。也可导入“真王核心-花名册-V0.3.12-网络加载.json”。请先停用旧脚本，不要同时启用两个版本。新用户仍需安装酒馆助手、MVU 和配套世界书。

脚本 1.85 MB；93 张图片合计 91.93 MB。图片按需加载并单独缓存，分离图片不会让首次浏览全部画面的总流量消失。完整内嵌版仍保留在开发项目的 release 目录。

图片主源为 GitHub Pages，失败时尝试 jsDelivr 的固定发布 assets-v0.3.11。该发布必须只包含运行素材，避免打包整个历史成品仓库。

图片按原始文件内容的 SHA-256 命名，不重绘、不缩放、不重新压缩。详细来源与文件校验见 asset-manifest.json 和 SHA256SUMS.txt。
