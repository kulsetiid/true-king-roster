# 真王核心 · 轻量联网版

版本：V0.3.16。

```js
import 'https://kulsetiid.github.io/true-king-roster/index.js';
```

仍使用原来的一行导入地址。也可导入“真王核心-花名册-V0.3.16-网络加载.json”。请先停用旧脚本，不要同时启用两个版本。新用户仍需安装酒馆助手、MVU 和配套世界书。

脚本 3.96 MB；108 张图片合计 94.41 MB。图片按需加载并单独缓存，分离图片不会让首次浏览全部画面的总流量消失。完整内嵌版仍保留在开发项目的 release 目录。

图片主源为 GitHub Pages，失败时尝试 jsDelivr 的固定发布 assets-v0.3.16。该发布必须只包含运行素材，避免打包整个历史成品仓库。

图片按原始文件内容的 SHA-256 命名，不重绘、不缩放、不重新压缩。详细来源与文件校验见 asset-manifest.json 和 SHA256SUMS.txt。

## V0.3.16 · 秘密补给

点击艾琳个人选单中的“开启秘密补给”，或点击客厅壁炉，即可进入番茄酱的地下补给室。普通、优良、稀有、史诗、传说、神话盲盒分别售价 10、30、90、270、810、2430 FP。购买后直接扣除 FP 并放入背包，开出什么留到剧情中决定。取货、补货的小帮手和包裹位于番茄酱图层下面。已有网络加载地址继续有效，刷新酒馆即可获取更新。
