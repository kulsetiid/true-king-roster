# 真王核心-纸剧场

当前版本：**V0.3.23**。用于SillyTavern酒馆助手与MVU。

## 本次更新

- API连接新增自动（默认）、HTTP和HTTPS选择；地址补全、获取模型、连接检查和正式请求使用同一协议。
- 关闭塔罗面板、返回正常聊天后继续后台解读；重新打开可查看原请求的进度、结果或失败原因。
- 回复核对原聊天与牌局后追加到手记；切换聊天时暂存结果，回到原聊天再收录，避免覆盖或串写。
- 银白色悬浮小帮手新增举牌提示，完成后可直接打开对应解读；提示板与通知接口可供后续功能复用。
- 未读完成与失败通知可在刷新后恢复；运行中的请求仍会随整页刷新、关闭或核心卸载而终止。
- 沿用克里斯蒂娜的人物、四项权柄、关系、纸卡动作、塔罗牌、统一API设置及已定稿对白正则。

## 一行网络加载

```js
import 'https://kulsetiid.github.io/true-king-roster/index.js';
```

网络加载版跟随同一地址更新；轻量联网版固定使用下载时的脚本。二者均按需加载图片。当前脚本约4.35MB，168张运行素材合计约116.28MB。图片主源为GitHub Pages，失败时使用固定素材标签assets-v0.3.23的jsDelivr地址。

密钥按设置仅保存在用户当前浏览器，发布包不包含本地密钥、聊天存档或开发配置。

来源整包已通过71项针对性离线检查及模拟浏览器流程。本次仅生成和上传联网成品，未重新运行测试，未连接真实内网API或进行实际酒馆导入。
