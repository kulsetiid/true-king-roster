# 真王核心-花名册

版本：**V0.3.5**。用于 SillyTavern 酒馆助手。

真王核心-花名册 V0.3.5：小帮手在9个家具点位之间随机落位、轻轻浮动和邻近巡游，可以躲在沙发扶手旁或在工作区忙碌；保留点击迅速逃跑与100FP奖励，以及纸剧场、花名册原有功能。

## 一行网络加载

在酒馆助手中新建脚本，名称填写“真王核心-花名册”，将以下内容粘贴到脚本代码中并启用：

```js
import 'https://kulsetiid.github.io/true-king-roster/index.js';
```

也可直接导入 [网络加载JSON](https://kulsetiid.github.io/true-king-roster/%E7%9C%9F%E7%8E%8B%E6%A0%B8%E5%BF%83-%E8%8A%B1%E5%90%8D%E5%86%8C-V0.3.5-%E7%BD%91%E7%BB%9C%E5%8A%A0%E8%BD%BD.json)。网络版和完整版的脚本ID相同，用于替换升级，**不要同时启用多个版本**。

## 配套安装

需要先安装酒馆助手及 MVU，并使用与本项目匹配的命定之诗角色卡环境。网络入口只加载脚本，不自动安装世界书或正则。

1. 导入网络加载JSON，或自行填写上面的一行代码。
2. 导入并启用本仓库中的固定世界书。
3. 按需导入三名冠冕之灵的对白美化正则。已有相同配套文件的用户无需重复导入。
4. 停用旧版 EX、v2.b、v3 或独立姬月愿望脚本，刷新酒馆，通过小帮手进入孤儿院纸剧场，点击中央花名册编辑出场编制，点击挂墙小黑板打开姬月的愿望。
